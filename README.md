# Network Segmentation & ACL-Based Traffic Control

## Project Overview
A basic network security lab created using Cisco Packet Tracer to understand network segmentation, IPv4 addressing, routing, and Access Control Lists (ACLs).

## Technologies & Tools
- Cisco Packet Tracer
- IPv4
- Routing
- Access Control Lists (ACL)
- ICMP

## Network Setup
- Two separate IPv4 network segments
- Cisco 2911 Router
- Two Cisco 2960 Switches
- Two End Devices

## Key Activities
- Configured router interfaces for two networks
- Assigned IPv4 addresses and default gateways
- Verified connectivity between network segments
- Configured an extended ACL to restrict ICMP traffic between specified hosts
- Verified ACL operation using `show access-lists`

## Learning Outcome
Gained practical understanding of basic network segmentation, router configuration, connectivity testing, and ACL-based traffic control.
